# ShipsEar CNN & ResNet18 Reproduction

A **notebook-only implementation** of the CNN and ResNet18 baselines from:

**STM: Spectrogram Transformer Model for Underwater Acoustic Target Recognition**  
Li et al., *Journal of Marine Science and Engineering*, 2022.

> This project intentionally excludes STM and all Transformer components. The complete implementation is contained in one self-contained Jupyter notebook.

## Main implementation

Open and run:

[`notebooks/ships_ear_complete_implementation.ipynb`](notebooks/ships_ear_complete_implementation.ipynb)

The notebook contains the full workflow:
- Inspect and validate dataset metadata.
- Convert original ShipsEar recordings into non-overlapping 5-second clips.
- Build Dataset A (random clip-level 70:15:15 split).
- Build Dataset B (chronological source-recording split; clips from one recording remain together).
- Extract STFT, 128-bin FBank, and MFCC features.
- Define and train the two-convolution CNN and single-channel ResNet18.
- Evaluate models and save metrics, classification reports, checkpoints, training curves, and confusion matrices.
- Compare your own results with the published paper values.

There are no separate `.py` implementation modules or command-line scripts. Run notebook cells in order.

## Environment

The first notebook cell installs the required packages. It is designed for Google Colab or Jupyter with Python 3.10+ and can use CUDA when available.

## Dataset setup

The ShipsEar audio dataset is not included in this repository. Obtain it from the course-provided source and keep the original recordings outside GitHub.

Create a metadata CSV with:
- `audio_path`: original recording path, absolute or relative to the audio root.
- `class_label`: one of `A`, `B`, `C`, `D`, `E`.
- `recording_order`: chronological key for the original recording. Strongly required for a meaningful Dataset B split.

The five classes are:
- A: fishing boats, trawlers, mussel boats, tugboats and dredgers
- B: motorboats, pilot boats and sailboats
- C: passenger ferries
- D: ocean liners and Ro-Ro vessels
- E: background noise

The notebook includes cells to inspect Excel metadata and map its actual columns. Do not guess labels or chronology.

## Published paper reference values

| Experiment | Dataset A | Dataset B |
|---|---:|---:|
| ResNet18 + STFT | 76.9% | 60.1% |
| ResNet18 + FBank | 93.8% | 88.2% |
| ResNet18 + MFCC | 93.8% | 85.5% |
| CNN baseline | 84.0% | 39.9% |
| ResNet18 baseline | 93.7% | 88.1% |

The first three values are the paper's feature comparison; the final two are its model baseline comparison. They are reference values, not results generated by this repository.

## Reproducibility notes

- Dataset A uses random clip-level splitting; Dataset B splits original recordings chronologically before assigning clips.
- Dataset B requires verified chronology from the supplied metadata. Alphabetical path sorting is only a fallback and must be checked.
- Audio is resampled to 16 kHz. STFT uses a 254-point FFT and Hann window. FBank uses 128 mel filters and a 10 ms hop.
- MFCC uses 40 coefficients, per-clip standardization and resizing to 128×128 are implementation choices. The CNN dense-layer dimensions are also implementation-defined where the paper is not fully explicit.
- Exact sample counts depend on the supplied recordings and metadata. Do not claim exact reproduction until split counts and mappings are verified.
- No experimental accuracy is claimed until the notebook is run on the actual dataset.
